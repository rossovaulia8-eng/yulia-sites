# Заявки с сайта Триггер Бара → Telegram и почта

Cloudflare Worker — посредник между формами сайта, Telegram и почтой бара.

Зачем посредник: чтобы написать в Telegram, нужен токен бота. Код сайта виден
любому посетителю, поэтому токен туда класть нельзя. Воркер хранит токен у себя,
сайт просто говорит ему «прими заявку».

```
форма брони        →  воркер (Cloudflare)  →  группа в Telegram
форма вопросов     →  здесь лежат           →  письмо на info@triggerpub.ru
                      токен и пароль
```

У каждой формы свой канал, заявки не дублируются:

- **бронь стола → Telegram.** Гость ждёт стол на конкретное время, сотрудник
  должен увидеть заявку сразу.
- **вопрос с сайта → почта.** На вопрос отвечают не спеша, и в почте удобнее:
  переписка хранится, можно переслать, можно ответить одной кнопкой.

В обоих случаях сайт говорит «принято» только после того, как сообщение реально
ушло. Если канал недоступен, гость видит телефон бара, а не ложное «отправлено».

## Что уже сделано

- `src/index.js` — код воркера (проверка полей, защита от спама, отправка в Telegram).
- В `sites/trigger/site/assets/script.js` обе формы отправляют заявку на воркер
  (`FORMS_ENDPOINT`). Если вписать туда пустую строку — вернётся демо-режим.

## Порядок подключения

### 1. Создать бота и группу

По инструкции `~/Desktop/WD/telegram-bot-client-instruction.docx`:
создать бота через `@BotFather`, создать группу для броней, добавить в неё бота
и написать в группе любое сообщение.

На выходе нужен **токен** вида `1234567890:AAExample…`.

### 2. Узнать id группы

Подставить свой токен и выполнить:

```bash
curl -s "https://api.telegram.org/bot<ТОКЕН>/getUpdates" | grep -o '"chat":{"id":-[0-9]*'
```

Получится число с минусом, например `-1001234567890`. Это и есть `CHAT_ID`.

Если ответ пустой — написать в группе ещё одно сообщение и повторить.

### 3. Выложить воркер

```bash
cd /Users/ulia/webdesign/sites/trigger/worker
npx wrangler login      # откроется браузер, войти в Cloudflare
npx wrangler deploy
```

В ответе будет адрес вида `https://trigger-bar-forms.ИМЯ.workers.dev` — сохранить его.

### 4. Положить секреты

```bash
npx wrangler secret put BOT_TOKEN   # вставить токен, Enter
npx wrangler secret put CHAT_ID     # вставить число с минусом, Enter
```

Секреты видны только воркеру. В файлах проекта и в git их нет.

### 5. Включить отправку на сайте

В `sites/trigger/site/assets/script.js` вписать адрес из шага 3:

```js
var FORMS_ENDPOINT = 'https://trigger-bar-forms.ИМЯ.workers.dev';
```

Затем запушить сайт в GitHub — Timeweb задеплоит автоматически.

### 6. Проверить

Отправить тестовую бронь на сайте. Сообщение должно прийти в группу.
Если не пришло — смотреть журнал воркера:

```bash
npx wrangler tail
```

## Почта: письма на info@triggerpub.ru

Сюда уходят вопросы с формы обратной связи — это её единственный канал,
поэтому воркер дожидается отправки письма и только потом отвечает сайту.
Если письмо не ушло, гость увидит телефон бара.

Письма идут через почтовый сервер клиента на reg.ru. Свой сервер выбран
не случайно: он подписывает письма (SPF и DKIM настроены), поэтому они не
попадают в спам. Сторонние сервисы рассылок не нужны.

### Отдельный ящик для отправки

Письма отправляются **не** с `info@`, а с отдельного ящика — `site@triggerpub.ru`.
Причина: чтобы отправлять почту, воркеру нужен пароль. Если положить туда пароль
от `info@`, то доступ ко всей переписке бара будет лежать в настройках Cloudflare.
С отдельным ящиком в худшем случае можно только отправлять письма.

Ящик создаётся в панели хостинга reg.ru → раздел «Почта» → «Создать ящик».

### Секреты

```bash
cd /Users/ulia/webdesign/sites/trigger/worker
npx wrangler secret put SMTP_USER   # site@triggerpub.ru
npx wrangler secret put SMTP_PASS   # пароль от этого ящика
npx wrangler deploy
```

Пока этих двух секретов нет, форма вопросов отвечает ошибкой и показывает
гостю телефон бара. Бронь через Telegram при этом работает как обычно.

### Параметры подключения

Заданы прямо в `src/index.js`:

```js
const MAIL_HOST = 'server262.hosting.reg.ru';  // не mail.triggerpub.ru!
const MAIL_PORT = 465;
const MAIL_TO = 'info@triggerpub.ru';
```

Хост именно `server262.hosting.reg.ru`, потому что сертификат хостинга выдан
на `*.hosting.reg.ru`. При подключении к `mail.triggerpub.ru` имя не совпадёт
с сертификатом и соединение оборвётся.

Если клиента переселят на другой сервер хостинга, имя изменится — смотреть
актуальное в панели reg.ru, в параметрах почтового клиента.

### Если письма не приходят

```bash
npx wrangler tail
```

В журнале будет строка `mail error` с причиной. Частые случаи: сменили пароль
ящика, удалили ящик `site@`, хостинг переехал на другой сервер.

## Если меняется адрес сайта

Когда сайт переедет на домен клиента, добавить этот домен в `ALLOWED_ORIGINS`
в `src/index.js` и выполнить `npx wrangler deploy` заново. Без этого браузер
заблокирует отправку: воркер принимает заявки только со «своих» адресов.

## Если токен утёк

`@BotFather` → команда `/revoke` → выбрать бота → получить новый токен →
`npx wrangler secret put BOT_TOKEN` заново. Старый токен сразу перестаёт работать.
