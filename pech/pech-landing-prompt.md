Создай одностраничный лендинг для «ПЕЧЬ» — ресторана русской фьюжн-кухни.
Это тренировочный проект для портфолио (реального клиента, реальных фото
и видео нет), поэтому вместо настоящих съёмок заведения используй фон на
CSS (тёмный угольно-терракотовый градиент + текстура дыма/золы), свободные
изображения без лицензионных ограничений или короткий футажный видеоролик
без лицензионных ограничений — без выдумывания несуществующих реальных
фото/видео заведения.

Готовый результат — ОДИН самодостаточный HTML-файл: все изображения (лого,
иконки) встроены как data-URI или нарисованы через SVG/CSS прямо в коде,
без ссылок на внешние файлы — это критично для публикации (например,
перетаскиванием в Netlify), где отдельная папка с картинками может не
загрузиться вместе с HTML. Исключение для видео — см. раздел «Технические
требования».

ФИЛОСОФИЯ БРЕНДА
Главный посыл: «Русская кухня, которую топили сто лет назад — подаём так,
будто придумали её заново».
В основе — настоящая дровяная печь и долгое томление, а не скорость и
полуфабрикаты; классические рецепты получают фьюжн-подачу без потери сути.
Три принципа:
1. Дровяной огонь — готовим в настоящей дровяной печи, а не на газу или
   электричестве; дым и уголь дают вкус, который нельзя подделать.
2. Томление, а не скорость — щи, рагу и томлёное мясо проводят в печи
   часами; меню не рассчитано на «быстро поесть за 20 минут».
3. Классика в новой подаче — блины, пельмени, борщ — узнаваемые рецепты,
   но с фьюжн-акцентами (азиатские, скандинавские ноты) в подаче и составе.

1. Хедер (закреплён при скролле) — монограмма «П» в круге, стилизованная
   под очертания печной заслонки, + название ПЕЧЬ, навигация (О нас /
   Меню / Дегустационный сет / Банкеты / Контакты), кнопка «Забронировать

2. Хиро — сразу под хедером, во всю ширину, ФОНОВОЕ ВИДЕО в цикле (огонь

   `autoplay muted loop playsinline`), поверх — тёмный градиент для
   читаемости текста. Обязательно указать атрибут `poster` (статичный

4. Философия — заголовок «Русская кухня, которую топили сто лет назад —
   подаём так, будто придумали её заново», три карточки-принципа (см.

5. Цифры — «8 часов томления борща», «12 блюд готовятся на дровяном

6. CTA-блок (повтор призыва) — короткий текст-напоминание + две кнопки:

7. Дегустационный сет «У печи» (блок спецпредложения) — название, короткое

   классика в новой подаче, десерт на углях), цена 3 900 ₽ с человека,

   Публичная оферта, Реквизиты), часы работы «12:00 — 23:00, ежедневно»,
   телефон-плейсхолдер, ссылка «Сайт создан [твоё имя/бренд]».

ФОРМЫ ЗАЯВОК
1. Форма брони стола (доступна из хедера и хиро-кнопки): имя, телефон,
   дата, время, количество гостей. Кнопка «Отправить заявку».
2. Форма брони дегустационного сета (из блока 7): имя, телефон, дата
   (только будни), количество гостей. Кнопка «Забронировать сет».
Обе формы — без бэкенда: по сабмиту показываем сообщение об успехе
(«Спасибо, мы перезвоним в течение часа») и дублируем данные заявки в
консоль/localStorage — реальная отправка (на email/в Telegram-бот)
подключается отдельно при переносе с тренировочного макета на боевой.

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
— Один статический HTML-файл, все ассеты (лого, иконки) — как data-URI/
  inline SVG внутри самого файла, без папки images и без внешних запросов.
— ИСКЛЮЧЕНИЕ ДЛЯ ВИДЕО: видео как data-URI раздувает файл до десятков
  мегабайт (в отличие от картинок/SVG) — это уже не «лёгкий один файл»,
  а неудобно для публикации и долго грузится у гостей. Поэтому видео —
  единственный ассет, для которого можно либо (а) подключить его отдельным
  файлом рядом с HTML с явной пометкой в промте «нужна папка с видео при
  публикации», либо (б) сослаться на видео с бесплатного хостинга
  (например Coverr/Pexels — с явной внешней ссылкой на .mp4), либо
  (в) для простоты тренировочного макета — заменить видеофон на
  CSS-анимацию (например, мерцающий градиент, имитирующий отблески огня)
  и оставить видео как опцию «для боевой версии».
— Адаптивная вёрстка (мобильный экран — приоритет), на мобильных при
  медленном интернете — фолбэк на статичный poster вместо видео.
— Язык интерфейса — русский.
